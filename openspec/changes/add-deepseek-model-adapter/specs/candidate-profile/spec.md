## MODIFIED Requirements

### Requirement: 候选人资料保持本地与最小暴露
系统 MUST 不在普通日志、错误摘要或作业事件中记录完整简历文本。使用本地演示模型时，初筛 MUST 在本机完成且不产生外部模型请求；用户显式启用外部模型时，系统 SHALL 在发送前确定性移除手机号和邮箱等直接身份信息，并只发送当前任务所需的简历内容。

#### Scenario: 初筛处理失败
- **WHEN** 包含简历输入的初筛作业失败
- **THEN** 错误记录只包含脱敏错误码和摘要，不包含简历正文或联系方式

#### Scenario: 使用本地演示模型
- **WHEN** 用户未显式启用外部模型 provider
- **THEN** 简历只在本机处理，不产生外部模型请求

#### Scenario: 使用 DeepSeek 初筛
- **WHEN** 用户显式配置 DeepSeek provider 并启动初筛
- **THEN** 系统先移除手机号和邮箱，再发送完成当前匹配任务所需的最小简历内容
