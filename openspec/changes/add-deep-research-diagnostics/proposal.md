## Why

深研页面目前只显示笼统的研究失败，用户无法判断失败发生在公司确认、网页读取还是后续研究阶段，也无法据此采取下一步操作。真实联网研究中，公开来源不可读是可恢复的资料不足，不应被误解为 API 配置失败。

## What Changes

- 为深研 Run 持久化安全、可展示的阶段诊断与来源读取统计，并保持旧状态兼容。
- 在岗位详情将深研进度展示为五个高层流程节点，标记完成、执行中、等待确认、失败和未开始状态。
- 对无可读公司来源的情况转为用户确认公司，提供补充官网或跳过确认的操作，而非继续调用模型并失败。
- 仅在深研处于活动状态时轮询；终态依赖 SSE 刷新并停止轮询。

## Capabilities

### New Capabilities

- `deep-research-diagnostics`: 深研流程状态、失败诊断、资料不足引导与页面可视化。

### Modified Capabilities

- 无。

## Impact

涉及深研契约、`DeepResearchApplication` 的来源读取和异常收口、岗位详情深研组件及其聚焦测试。不新增外部服务、数据库迁移或敏感信息输出。
