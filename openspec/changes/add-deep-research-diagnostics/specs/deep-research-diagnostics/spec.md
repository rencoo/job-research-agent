## Purpose

为深研任务提供安全且可操作的运行诊断，使用户能了解流程进度、资料读取受限的位置，并在不泄露内部服务细节的前提下采取恢复操作。

## ADDED Requirements

### Requirement: 深研流程状态可见

系统 SHALL 在岗位详情中将深研展示为核实公司、研究公司、收集岗位证据、核验证据与评估、生成报告五个节点，并标识节点的完成、进行中、等待用户确认、失败或未开始状态。

#### Scenario: 研究在执行中

- **WHEN** 深研 Run 正在执行任一阶段
- **THEN** 页面标识对应高层节点为进行中，并将此前节点展示为完成、后续节点展示为未开始

#### Scenario: 研究阶段失败

- **WHEN** 深研因工具或模型异常终止
- **THEN** 页面标识对应高层节点为失败，展示安全的失败说明和可执行的下一步操作，而不展示服务商原始响应、密钥或内部错误码

### Requirement: 来源读取资料不足可恢复

系统 SHALL 持久化来源读取的尝试数、成功数和可展示失败原因汇总；当公司核实阶段没有任何可读公开来源时，系统 MUST 转为等待用户确认公司，不调用公司识别模型。

#### Scenario: 所有公司来源不可读

- **WHEN** 公司核实搜索返回来源但所有来源均无法安全读取
- **THEN** Run 进入等待用户确认状态，页面说明公开资料不足并提供补充公司信息或跳过公司确认的操作

### Requirement: 终态停止轮询

系统 SHALL 仅在深研 Run 为活动状态时进行定时状态查询；任务进入完成、失败、取消或被替代等终态后 MUST 停止定时查询，同时保留 SSE 对状态变更的刷新能力。

#### Scenario: 研究完成后查看详情

- **WHEN** 深研 Run 已进入终态
- **THEN** 页面继续展示最终流程状态和报告，但不再发起周期性 Run 或深研视图查询
