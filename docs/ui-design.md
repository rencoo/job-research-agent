# UI 视觉方向

岗位研究是一款帮助用户判断机会的个人工作工具。界面采用 Apple 风格的中性色、清晰排版和克制层次，将注意力集中在岗位正文、匹配依据和下一步操作。

## 视觉系统

共享样式位于 `apps/web/src/styles.css`。

- 浅灰画布 `#f5f5f7`、白色内容表面、石墨色正文 `#1d1d1f`。
- 蓝色 `#0066cc` 用于主操作、当前步骤、链接和焦点；绿色和橙色保留状态含义。
- 使用系统字体；正文与控件以 13–14px 为主，辅助文字 12px，分区标题 15–18px，页面标题 28–36px。
- 常规间距以 4 / 8 / 12 / 16 / 20 / 24 / 32px 为节奏。
- 控件圆角 8px、主要内容表面 16px、对话框 20px。阴影只用于首页工作区和浮层。
- 主要内容使用白色表面；内部章节依靠间距和分隔线区分。最近记录直接呈现在画布上，偏好和报告维度避免再嵌套卡片。

## 页面与交互

- 首页层级：目标说明 → 三步流程 → JD 输入 → 简历上下文 → 识别操作 → 最近记录。
- 桌面首页居中呈现，820px 内容宽度；手机上标题左对齐，保留可读正文与明确主操作。
- 历史页保持列表结构，筛选位于列表上方；简历与偏好采用分区设置页面。
- 简历、偏好和岗位草稿保留预览优先模式；进入编辑时才出现输入控件。
- 权重使用“较低 / 一般 / 较高”分段选择，白色选中项区分当前值。
- 按钮、链接和输入保留悬停、键盘焦点、按下和禁用状态；触屏显示编辑入口，减少动态效果偏好下禁用过渡。

## 验证范围

前端测试、Web 类型检查及 diff 检查；浏览器检查首页、简历弹窗、偏好、历史和报告，覆盖桌面与 390px 窄屏。视觉调整不需要触发真实模型分析或更改已保存资料。
